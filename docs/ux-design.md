# UX Design Specification: SmartFish

**Author:** Jody  
**Date:** 2026-01-10

---

## Executive Summary

### Project Vision

SmartFish 是 BettaFish 舆情分析系统的增强版本，通过双轨选择系统（模板 + 分析方法）让用户获得有方法论指导的可行动洞察。

### Target Users

| 用户类型 | 技术水平 | 核心需求 | 使用模式 |
|---------|---------|---------|---------|
| 产品经理 | 中等 | 快速验证产品方向 | 纯模板 / 混合 |
| 创业者 | 初级-中等 | 发现市场机会 | 纯模板 |
| 市场分析师 | 中等-高级 | 深度行业洞察 | 混合 / 纯方法 |

### Key Design Challenges

1. **选择复杂度** - 8 个模板 + 38 种方法，如何避免决策瘫痪？
2. **认知负担** - 用户不了解模板/方法的具体内容
3. **信心缺失** - 盲选导致不确定感

### Design Opportunities

1. **预览即决策** - 选择前看到预期结构
2. **智能推荐** - 根据输入自动推荐
3. **渐进式披露** - 方法选择默认折叠

## Core User Experience

### Defining Experience

**核心用户动作：** 输入主题 → 选择模板 → (可选)选择方法 → 生成报告

**体验原则：**
- 默认选项足够好，高级选项是锦上添花
- 每一步可预览，减少不确定性
- 30 秒内完成首次选择

### Platform Strategy

| 平台 | 优先级 | 支持程度 |
|-----|-------|---------|
| Web 桌面 (>1024px) | P0 | 完整功能 |
| Web 平板 (768-1024px) | P1 | 完整功能 |
| Web 手机 (<768px) | P2 | 基本选择 |

### Effortless Interactions

| 交互 | 设计目标 |
|-----|---------|
| 选择模板 | 悬停预览章节数，点击预览完整结构 |
| 选择方法 | 悬停显示说明，无需打开新页面 |
| 组合选择 | 智能推荐标记，减少决策负担 |

### Critical Success Moments

1. **首次选择成功** - 用户第一次就选对模板
2. **预览即理解** - 看到预览就知道是否合适
3. **方法增强惊喜** - 发现方法论让报告更有深度

## Emotional Response

### Desired Feelings

| 阶段 | 期望情感 | 设计策略 |
|-----|---------|---------|
| 进入页面 | 清晰 | 简洁布局，明确引导 |
| 选择模板 | 有信心 | 预览功能，推荐标记 |
| 选择方法 | 好奇 | 方法说明，适用场景 |
| 生成报告 | 期待 | 进度反馈 |

### Emotional Pitfalls

- ❌ 选项太多 → 决策瘫痪
- ❌ 不了解选项 → 不确定感
- ❌ 选错后发现不对 → 挫败感

## User Journeys

### Journey 1: 新手用户 - 纯模板模式

**对应 PRD:** US-2.1 报告模板选择

```
小王输入"宠物社交App市场分析"
    ↓
看到 8 个模板卡片，"市场竞争格局"有 ✓推荐 标记
    ↓
点击 [预览]，看到 6 个章节结构
    ↓
点击 [使用此模板]
    ↓
跳过分析方法（折叠状态）
    ↓
点击 [生成报告]
```

**设计要点：**
- 推荐标记降低决策负担
- 预览弹窗确认选择正确
- 方法选择默认折叠，不干扰新手

### Journey 2: 进阶用户 - 混合模式

**对应 PRD:** US-2.3 三种使用模式

```
老李输入"新能源汽车品牌声誉"
    ↓
选择"企业品牌声誉分析"模板
    ↓
展开"分析方法增强"
    ↓
切换到"头脑风暴"标签，选择"六顶思考帽"
    ↓
切换到"高级引导"标签，选择"五个为什么"
    ↓
悬停 [?] 查看方法说明
    ↓
点击 [生成报告]
```

**设计要点：**
- 标签页分类 38 种方法
- 悬停提示避免页面跳转
- 底部显示已选方法摘要

### Journey 3: 专家用户 - 纯方法模式

**对应 PRD:** US-2.3 三种使用模式

```
小张输入"AI伴侣产品机会"
    ↓
不选择模板（使用默认）
    ↓
展开"分析方法增强"
    ↓
选择"第一性原理" + "红队蓝队" + "利益相关者圆桌"
    ↓
点击 [生成报告]
```

**设计要点：**
- 不强制选择模板
- 纯方法模式下章节由方法论决定

## UX Patterns

### Pattern 1: 模板卡片

**对应 FR:** FR1, FR2, FR3, FR4

```
┌─────────────────────────────┐
│ 🏢                          │
│ 企业品牌声誉分析             │
│                             │
│ 品牌监测 | 声誉管理          │  ← 标签 (来自 meta)
│                             │
│ 7 个章节                    │  ← 章节数
│                             │
```

**交互规格：**
| 触发 | 动作 |
|-----|------|

| ✓推荐 | 根据用户输入动态显示 |

| 点击 [清除全部] | 取消所有已选方法 |

|-----|------|---------|---------|
| 桌面 | >1200px | 4列 | 6列复选框 |

| 平板 | 768-1024px | 2列 | 3列复选框 |

- 模板预览弹窗 → 全屏抽屉
- 方法选择器 → 底部抽屉
